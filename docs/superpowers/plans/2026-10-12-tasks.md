# Tasks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Philip and Jack one kind of to-do (a line, a person, a due date, usually a client) that shows in Overview › Today and on the client page, so client promises and handoffs between them stop getting lost.

**Architecture:** A Supabase `tasks` table. Pure logic in `src/core/tasks.js` (tested under Node). One module, `src/sections/tasks.js`, owns the reads, the writes, the one row and the one native `<dialog>`; Overview's classic script reaches it as `window.GeckoTasks` and the client page imports it. Client follow-ups (`client_activity.follow_up_*`) are copied into tasks by the migration and no longer read or written.

**Tech Stack:** Static site, plain ES modules, no build step, no framework. Supabase JS (already loaded by `src/core/supabase.js`). Tests are plain Node scripts using `node:assert/strict`.

**Design note:** `docs/superpowers/specs/2026-10-12-tasks-design.md`. Read it first.

## Global Constraints

- Branch `feat/tasks` (already created; the design note is committed on it). Feature branch → PR → merge. Do not push or open the PR without Jack saying so.
- No bundler, no framework, no TypeScript, no new dependency, no chart or UI library.
- Schema changes only as a file in `supabase/migrations/`; never change the database by hand. The Supabase GitHub integration applies it on merge to `main`.
- Every table has RLS on and a staff policy (`tests/supabase-migration.mjs` enforces it).
- Every rendered value goes through `escapeHtml`. A client name is drawn with `clientLink(name)`.
- An error state must never look like an empty state: a failed read is named ("Not checked: tasks (reason)" / "Tasks didn’t load: reason").
- Existing CSS tokens only (`--card`, `--border-dim`, `--green`, `--amber`, `--red`, `--muted`, `--faint`, `--white`, `--inset`, `--panel`, `--radius`, `--radius-sm`, `--radius-pill`, `--who`). - No text character used as an icon (`☎ ⚠ ↗ ↙ ✕ ▸` fail `tests/icons.mjs`).
- Sentence case for every label.
- `src/core/*.js` and `src/sections/*.js` must not touch `window` or `document` at module top level (they are imported under Node by the tests).
- People are stored as first names from `PEOPLE` in `src/core/team.js`: `'Philip'`, `'Jack'`.
- Run the whole suite before every commit: `for t in tests/*.mjs; do node $t; done`. Every script prints one line ending `ok` or `all tests passed`; any stack trace is a failure.
- Commit messages end with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- The local preview (`.claude/preview/`, git-ignored, mock sign-in as Jack Morris, in-memory database) is how pages are checked: `node .claude/preview/build.mjs` after every edit, then the `hq-preview` server on port 8803. Never commit anything from `.claude/preview/`.

-- Tasks: client promises and handing work over (Jack, 12 Oct 2026).
-- One line of what needs doing, who does it, when it is due and usually which client. Shown on
-- Overview › Today and the client page; a client note's follow-up makes one.
-- Design: docs/superpowers/specs/2026-10-12-tasks-design.md

create table public.tasks (
  id           bigint generated always as identity primary key,
  title        text not null check (title <> ''),
  note         text not null default '',
  client_name  text not null default '',                 -- '' = not about one client
  assigned_to  text not null check (assigned_to <> ''),  -- 'Philip' | 'Jack' (PEOPLE in src/core/team.js)
  assigned_by  text not null default '',                 -- who last chose assigned_to
  seen_at      timestamptz,                              -- null = new to assigned_to
  due_on       date not null,
  done_at      timestamptz,
  done_by      text not null default '',
  activity_id  bigint unique references public.client_activity(id) on delete set null,  -- the client note it came from
  created_by   text not null default '',
  created_at   timestamptz not null default now(),
  modified_at  timestamptz not null default now()
);
create index tasks_open on public.tasks (due_on) where done_at is null;
create trigger tasks_touch before update on public.tasks
  for each row execute function public.touch_modified_at();
alter table public.tasks enable row level security;
create policy tasks_staff_all on public.tasks
  for all to authenticated using (public.is_gecko_staff()) with check (public.is_gecko_staff());

-- Follow-ups already on client notes become tasks, open and done alike: the first line of the note,
-- for whoever logged it, already seen, linked to the note. The site no longer reads or writes
-- client_activity.follow_up_on / follow_up_done_at / follow_up_done_by; the columns stay.
insert into public.tasks (title, client_name, assigned_to, assigned_by, seen_at, due_on, done_at, done_by, activity_id, created_by, created_at)
select coalesce(nullif(left(btrim(split_part(a.body, E'\n', 1)), 140), ''), 'Follow up'),
       a.client_name,
       case when a.created_by ilike 'jack%' then 'Jack' else 'Philip' end,
       case when a.created_by ilike 'jack%' then 'Jack' else 'Philip' end,
       a.created_at, a.follow_up_on, a.follow_up_done_at, a.follow_up_done_by, a.id, a.created_by, a.created_at
from public.client_activity a
where a.follow_up_on is not null
on conflict (activity_id) do nothing;
```

`touch_modified_at()` and `is_gecko_staff()` already exist (`20261007120000_foundations_projects.sql`). The copy runs once, when the integration applies the file; `on conflict … do nothing` makes it harmless if it were ever run again.

/* Tasks: client promises and handing work over. Pure logic (no window). Tested in tests/tasks.mjs.
   Design: docs/superpowers/specs/2026-10-12-tasks-design.md */

import { PEOPLE } from './team.js';
import { dueText, addDays } from './activity.js';
import { sameClient } from './client.js';

export { PEOPLE };
export const TITLE_MAX = 140;
export const NOTE_MAX = 500;
export const RED_AFTER_DAYS = 7;   // the rule follow-ups used: more than a week overdue is red
export const LATER_SHOWN = 5;      // Later shows this many, then "Show all n"
export const DONE_DAYS = 30;       // how far back the Done list goes

const day = d => String(d || '').slice(0, 10);
const oneLine = s => String(s || '').replace(/\s+/g, ' ').trim();
const daysBetween = (a, b) => Math.round((Date.parse(b + 'T00:00:00Z') - Date.parse(a + 'T00:00:00Z')) / 86400000);
const byDue = (a, b) => day(a.due_on).localeCompare(day(b.due_on)) || (a.id || 0) - (b.id || 0);
const RANK = { red: 0, new: 1, amber: 2 };

/** 'Jack Morris' or 'jack@gecko-it.com' → 'Jack'; '' when it is nobody in PEOPLE. */
export const personOf = name => PEOPLE.find(p => oneLine(name).toLowerCase().startsWith(p.toLowerCase())) || '';

/** The first line of a client note, as a task title. */
export const titleFromNote = body => oneLine(String(body || '').split('\n').find(l => l.trim()) || '').slice(0, TITLE_MAX);

/** Given to someone else and not opened by them yet. */
export const isNew = t => !t.done_at && !t.seen_at && !!t.assigned_by && t.assigned_by !== t.assigned_to;

/** 'red' more than a week overdue · 'new' a handoff not opened yet · 'amber' due today or overdue · '' later. */
export function level(t, today) {
  const late = daysBetween(day(t.due_on), today);
  if (late > RED_AFTER_DAYS) return 'red';
  if (isNew(t)) return 'new';
  return late >= 0 ? 'amber' : '';
}

/** "2 days overdue", "today", "tomorrow", otherwise "Fri 16 Oct". */
export function dueLabel(due, today) {
  const k = day(due);
  if (k <= addDays(today, 1)) return dueText(k, today);
  return new Date(k + 'T00:00:00Z').toLocaleDateString('en-GB', { weekday: 'short', day: 'numeric', month: 'short', timeZone: 'UTC' });
}

/**
 * Tidy what was typed. Returns { row } or { error }.
 * `prev` is the task being edited (null for a new one). A new task, or one whose person changed, is
 * handed over by `me`: seen straight away when it is their own, new to the other person otherwise.
 */
export function cleanTask(input, { me = '', today, now = new Date().toISOString(), prev = null } = {}) {
  const title = oneLine(input.title).slice(0, TITLE_MAX);
  const who = PEOPLE.includes(input.assigned_to) ? input.assigned_to : '';
  const due = day(input.due_on);
  if (!title) return { error: 'Write what needs doing.' };
  if (!who) return { error: 'Choose who it is for.' };
  if (!/^\d{4}-\d{2}-\d{2}$/.test(due)) return { error: 'Choose a due date.' };
  // An overdue task can still be edited; only a date newly set in the past is refused.
  if (due < today && (!prev || day(prev.due_on) !== due)) return { error: 'The due date is in the past.' };
  const row = { title, note: oneLine(input.note).slice(0, NOTE_MAX), client_name: oneLine(input.client_name), assigned_to: who, due_on: due };
  if (!prev || prev.assigned_to !== who) Object.assign(row, { assigned_by: me, seen_at: me && who !== me ? null : now });
  if (!prev) row.created_by = me;
  return { row };
}

/**
 * Open tasks for Overview › Today.
 * now: red, new handoffs, then due (each by date), every one with its `level`.
 * later: due after today and already seen. waiting: what `me` gave to someone else.
 * With `everyone` (or when `me` is nobody in PEOPLE) now and later hold both people's tasks and waiting is empty.
 */
export function groups(tasks, me, today, everyone = false) {
  const open = (tasks || []).filter(t => !t.done_at);
  const all = everyone || !me;
  const shown = (all ? open : open.filter(t => t.assigned_to === me)).map(t => ({ ...t, level: level(t, today) }));
  return {
    now: shown.filter(t => t.level).sort((a, b) => RANK[a.level] - RANK[b.level] || byDue(a, b)),
    later: shown.filter(t => !t.level).sort(byDue),
    waiting: all ? [] : open.filter(t => t.assigned_by === me && t.assigned_to !== me).sort(byDue)
  };
}

/** One client's open tasks, soonest first (the client page's Tasks panel). */
export function forClient(tasks, clientName) {
  return (tasks || []).filter(t => !t.done_at && t.client_name && sameClient(t.client_name, clientName)).sort(byDue);
}

/** Ticked in the last `days` days, newest first. */
export function doneRecently(tasks, today, days = DONE_DAYS) {
  const from = addDays(today, -days);
  return (tasks || []).filter(t => t.done_at && day(t.done_at) >= from).sort((a, b) => String(b.done_at).localeCompare(String(a.done_at)));
}
```

async function markSeen(t) {

/** Add a task from somewhere other than the dialog (a client note's follow-up). Throws with the reason. */
export async function addTask(input, extra = {}) {
  const { row, error } = cleanTask(input, { me: me(), today: today() });
  if (error) throw new Error(error);
  const sb = await connectSupabase({ interactive: true });
  const saved = must(await sb.from('tasks').insert({ ...row, ...extra }).select('*').single());
  if (TK.tasks) TK.tasks.push(saved); else await reload();
  emit();
  return saved;
}

async function saveForm(form) {
  if (TK.saving) return;
  const id = Number(form.dataset.id) || null, prev = id ? byId(id) : null, f = form.elements;
  const { row, error } = cleanTask({ title: f.title.value, note: f.note.value, client_name: f.client_name.value, assigned_to: f.assigned_to.value, due_on: f.due_on.value },
    { me: me(), today: today(), prev });
  if (error) { formError(form, error); return; }
  const submit = form.querySelector('[type="submit"]');
  TK.saving = true; submit.disabled = true;
  try {
    const sb = await connectSupabase({ interactive: true });
    const saved = id ? must(await sb.from('tasks').update(row).eq('id', id).select('*').single())
      : must(await sb.from('tasks').insert(row).select('*').single());
    if (!TK.tasks) await reload();
    else if (id) TK.tasks = TK.tasks.map(t => (t.id === id ? saved : t));
    else TK.tasks.push(saved);
    closeDialog(); emit();
    toast(id ? 'Task saved' : saved.assigned_to !== me() ? `Given to ${saved.assigned_to}` : 'Task added', 'success');
  } catch (err) {
    formError(form, 'Could not save: ' + (err.message || err));
  } finally { TK.saving = false; submit.disabled = false; }
}

/** Tick or untick. The row changes at once; a write that fails puts it back and says why. */
async function setDone(id, on) {
  const t = byId(id);
  if (!t) return;
  const before = { done_at: t.done_at, done_by: t.done_by }, wasJust = TK.justDone.has(id);
  const patch = on ? { done_at: new Date().toISOString(), done_by: me() } : { done_at: null, done_by: '' };
  Object.assign(t, patch);
  if (on) TK.justDone.add(id); else TK.justDone.delete(id);
  emit();
  try { const sb = await connectSupabase({ interactive: true }); must(await sb.from('tasks').update(patch).eq('id', id)); }
  catch (err) {
    Object.assign(t, before);
    if (wasJust) TK.justDone.add(id); else TK.justDone.delete(id);
    emit();
    toast('Could not update the task: ' + (err.message || err), 'error', 7000);
  }
}

async function remove(id, form) {
  if (!confirm('Delete this task?')) return;
  try {
    const sb = await connectSupabase({ interactive: true });
    must(await sb.from('tasks').delete().eq('id', id));
    TK.tasks = (TK.tasks || []).filter(t => t.id !== id);
    closeDialog(); emit();
    toast('Task deleted', 'success');
  } catch (err) { formError(form, 'Could not delete: ' + (err.message || err)); }
}


// ─── Wiring: one set of listeners on #app, for every page that draws tasks ───

function onClick(e) {
  const el = e.target.closest?.('[data-tk]');
  if (!el) return;
  const act = el.dataset.tk, id = Number(el.dataset.id) || null;
  if (act === 'add') openDialog(null, { client: el.dataset.client || '' });
  if (act === 'open' && byId(id)) openDialog(byId(id));
  if (act === 'close') closeDialog();
  if (act === 'due') {
    const form = el.closest('form');
    form.elements.due_on.value = el.dataset.date;
    form.querySelectorAll('[data-tk="due"]').forEach(b => b.classList.toggle('on', b === el));
  }
  if (act === 'undo' || act === 'reopen') setDone(id, false);
  if (act === 'del') remove(id, el.closest('form'));
  if (act === 'who') {
    TK.everyone = el.dataset.who === 'everyone';
    try { localStorage.setItem(WHO_KEY, TK.everyone ? 'everyone' : 'mine'); } catch { /* storage blocked */ }
    emit();

- [ ] **Step 7: Saving a note makes the task**

Replace the whole of `saveActivity()` with the following, and add the two helpers directly above it:

```js
const activityDraft = f => ({ kind: f.kind.value, body: f.body.value, contact_id: f.contact_id?.value || '', follow: f.follow_up_on.value, when: f.happened_at.value,
  duration: f.duration_min.value, direction: f.direction.value, task_title: f.task_title.value, task_who: f.task_who.value });

/** What is typed in Log activity survives a redraw (a task ticked above it, tasks re-read on coming back to the tab). */
function keepActivityDraft() {
  const f = els('clWrap')?.querySelector('[data-cl-form="activity"]')?.elements;
  if (f) CL.actDraft = { ...(CL.actDraft || {}), ...activityDraft(f) };
}

async function saveActivity(form) {
  if (CL.saving) return;
  const f = form.elements;
  const cid = f.contact_id?.value || '';
  const c = (CL.data.contacts || []).find(x => String(x.id) === cid);
  const started = CL.actDraft?.callStarted;
  let duration = f.duration_min.value;
  if (duration === '' && started && f.kind.value === 'call') duration = String(Math.max(1, Math.round((Date.now() - started) / 60000)));
  CL.actDraft = { ...(CL.actDraft || {}), ...activityDraft(f), duration };
  const { row, error } = cleanActivity({ kind: f.kind.value, body: f.body.value, contact_id: cid, contact_name: c ? (c.name || c.email) : '', follow_up_on: f.follow_up_on.value,
    happened_at: f.happened_at.value ? new Date(f.happened_at.value).toISOString() : '', duration_min: duration, direction: f.direction.value, now: new Date().toISOString() }, CL.name, today());
  if (error) { toast(error, 'warning'); return; }
  // The follow-up is a task (12 Oct): the note is saved without a date, then the task is made and linked to it.
  const { follow_up_on: due, ...noteRow } = row;
  const who = f.task_who.value, title = f.task_title.value || titleFromNote(row.body);
  CL.saving = true; render();
  try {
    const sb = await connectSupabase({ interactive: true });
    const saved = must(await sb.from('client_activity').insert({ ...noteRow, created_by: (els('userName')?.textContent || '').trim() }).select('id').single());
    let taskError = '';
    if (due) {
      try { await addTask({ title, client_name: CL.name, assigned_to: who, due_on: due }, { activity_id: saved.id }); }
      catch (err) { taskError = err.message || String(err); }
    }
    await reloadActivity(sb);
    CL.actDraft = null;
    if (taskError) toast(`Note saved. The task was not: ${taskError}. Add it from Tasks above.`, 'error', 9000);
    else toast(due ? `Logged · task for ${who} (${dueText(due, today())})` : 'Logged', 'success');
  } catch (err) {
    toast('Could not save: ' + (err.message || err), 'error', 7000);
  } finally { CL.saving = false; render(); }
}
```
